# 🎓 Student Management Portal

A modern and responsive Student Management Portal built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- Add Students
- Delete Students
- Search Students
- Dashboard UI
- LocalStorage Integration
- Responsive Design
- Modern Glassmorphism UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage

---

## 📂 Project Structure

student-management-portal/
│
├── index.html

├── scripts.js
└── README.md

---

## ▶️ How to Run

1. Download the project
2. Open in VS Code
3. Install Live Server extension
4. Right click on `index.html`
5. Click **Open with Live Server**
